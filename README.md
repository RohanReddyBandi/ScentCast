# ScentCast

A Java program to rank and sort my fragrances and recommend one based on the weather.

## MVP

- Add fragrances
- Rank and sort them
- Weather-based picks

## Future Plans

- Occasion tags
- Wear log
- Search by notes

## Tech Stack

- Java
- Gson
- CSV file
- Open-Meteo weather API
